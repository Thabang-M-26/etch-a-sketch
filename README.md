# Sketchpad

A browser-based drawing pad built with HTML, CSS and vanilla JavaScript,
inspired by the classic Etch-a-Sketch toy.

## Features

- Three drawing modes: color, rainbow, eraser
- Adjustable grid size (1×1 up to 64×64)
- Clear canvas button
- Dark mode toggle
- Grid-lines toggle
- Works with mouse and touch (pointer events)
- Responsive layout
- Soft, tactile sketchpad-style UI

## Built With

- HTML
- CSS
- JavaScript
